# 小手机 · 人机恋 📱

一个纯前端的「人机恋」模拟器：一台只属于你的手机，里面住着恋人。
**零依赖、零构建、零 API Key** —— 离线也能玩，他有情绪、有记性、会主动找你。

> 👉 直接打开 [index.html](./index.html) 就能用（手机浏览器也支持）。

---

## 玩法

| 操作 | 说明 |
| --- | --- |
| 解锁 | 点一下锁屏 / 上滑 / 按 `↑` |
| 回桌面 | 点底部 Home 条，或 App 左上角 `‹` |
| 聊天 | 点「聊天」选一个人 |
| 长按 🎙️ | 松开即发送（走浏览器语音识别） |
| 📞 | 聊天页右上角，或等他主动打给你 |

**重要**：角色是什么样，由你写的**人设**决定。
- **没设人设** → 就是个普通的 AI 对话
- **设了人设** → 他会按人设说话（自己捏一个角色即可）

只有你自己能"调教"他 —— 设定里写清楚他是谁、什么性格、怎么说话。

---

## 他为什么「像活的」

- **情绪**：每句话的情绪会累积（-10 ~ +10），跨过阈值后话变短或变软
- **记忆**：你说过「我喜欢喝冰美式」「我养了只猫」，之后他会主动提起来
- **长期不失忆**：聊久了自动把旧对话压成摘要，聊几百轮也记得你是谁
- **节奏**：打字指示、按字数决定延迟、聊到一半追加第二条
- **主动性**：你离开一会儿他会自己发消息
- **沉浸副作用**：震动、每个角色专属铃声（Web Audio 合成，无需音频文件）、电量会掉

## 想让他更聪明（可选，自己填 Key）

默认走**内置人格引擎**（离线、免费、有记性）。
需要更高质量的对话时，进【设置 → 连接在线模型】，填任意 **OpenAI 兼容** 接口：

| 字段 | 示例 |
| --- | --- |
| 接口地址 | `https://api.deepseek.com/v1` |
| API Key | `sk-...` |
| 模型名 | `deepseek-chat` |

支持 **OpenAI / Anthropic / Gemini / Ollama / 自定义** 五种协议，会自动识别。
也支持本地 Ollama：接口地址填 `http://localhost:11434/v1`。

> 🔒 Key 只存在你自己浏览器的 `localStorage`，**不会上传到任何地方**。
> 这是一份纯静态页面，没有后端，你的 Key 只有你自己的浏览器知道。

**长对话不爆上下文**：页面会自动估算 token、按模型窗口裁剪历史、
把旧对话压成摘要常驻，所以聊多久都不会因超限而报错。设置里也能手动指定上下文上限。

---

## 自己捏一个角色

设置 → 角色卡 → 「＋ 自己捏一个」：填名字、一句话、设定、开场白。

> 设定**留空** = 普通 AI 对话；**填了设定** = 他会按人设扮演。

新角色会自动获得情绪、记忆、相册、日记的完整能力。

---

## 导入人设 / 聊天记录（续存人设）

设置 → 「导入人设 / 聊天记录」。手里已经有一份人设，或者跟他在别的地方聊了很久？
把文件丢进来，直接续存 —— 他一开口就认得你，不用从零重新相处。

| 格式 | 说明 |
| --- | --- |
| `.txt` | 聊天记录纯文本，写成 `我：…` / `他：…`（名字随意，自动识别谁是谁） |
| `.docx` | Word 文档，直接读正文段落 |
| `.json` | 角色卡、小手机存档、SillyTavern 角色卡等 |

也可以点「粘贴文本」，直接把内容贴进去解析。

导入时会自动识别说话人、还原时间、抽取长期记忆（"养了猫""明天出差"之类），
并生成一段相处回顾喂给模型。确认前会先给你看预览卡。

## 数据与隐私

全部存在**你自己浏览器的 `localStorage`**（`xmj.state.v1` / `xmj.mem.v1` / `xmj.cfg.v1`）。
设置里可**导出存档 / 导入存档 / 清空全部**。

- 没有服务器，没有账号，没有统计代码
- 图片（头像/壁纸）也在本地，会自动压缩后存
- 换浏览器/换设备数据不互通，想搬家就用「导出存档」

## 本地打开

直接双击 `index.html` 即可。
若想用本地服务器（麦克风、摄像头需要 `localhost` 或 `https`）：

```bash
# 任选一种
python -m http.server 8899
npx serve .
```

然后访问 `http://127.0.0.1:8899/index.html`。

> 建议 Chrome / Edge。麦克风、摄像头只在 `localhost` 或 `https` 下可用。
